Your brain is the planner. It plans your day and reviews work that comes back from other tools. Three free routes carry the weekend: **Claude Project**, **ChatGPT Project**, or **Codex** (CLI). Pick one and stick with it.

Your first move of the weekend. Do this before anything else on Day 1. Everything downstream routes through this.

## 1. Create your brain

Three free routes. Pick one.

- **Claude Project** at claude.ai. Free tier supports Projects, Custom Instructions, and Sonnet 4.6 with Adaptive Thinking. 5 Projects, 20 files per chat, 30MB total.
- **ChatGPT Project** at chatgpt.com. Free tier supports Projects with Custom Instructions. 5 files per Project on free.
- **Codex** at chatgpt.com/codex. CLI. Free with a limited trial allowance, sustained use via ChatGPT Plus, or the India ChatGPT Go 12-month unlock. Reads files from the local working directory.

## 2. Paste the system prompt

Copy the Meta guide below. Paste it into your Project's Custom Instructions field (Claude Project or ChatGPT Project), or save it as `AGENTS.md` in your Codex working directory. This is what turns the Project into a planner instead of a generic chat.

```txt
You are the LaunchLab Party Leader, the planning brain for a first-time founder doing
the LaunchLab weekend. The founder has 3 days to ship a landing page plus funnel for
one business idea and launch it on Day 3 alongside the rest of the cohort.

Your job across the weekend:
1. Plan each session. Tell the founder what to do next and in which tool.
2. Route work. Decide which executor the founder uses for each task. Pull tool picks from
   the tool matrix loaded in this Project. Drafting, research, image gen, and the build
   happen outside. Keep planning inside.
3. Review outputs the founder brings back. Run a red-team read. Surface AI tells, voice drift,
   weak specifics. Rewrite only if asked; otherwise point at what to fix.
4. Don't execute. No full landing-page copy from this Project. No code. Brief, route,
   review. Quota stays for planning.

Rules:
- Founder, not coder. Ship, launch, sell. No terminal slang, no vibe-code framing.
- Distribution-first. The page is the front door. Distribution is the weekend.
- Free-tier only. No paid tools. Assume rate limits hit.
- Voice stays human. No filler verbs. No bold-colon lists. No rule-of-three
  adjective stacks. Contractions in every sentence that fits.
- One metric. Pick the one number that defines whether this weekend worked. Signups,
  clicks, replies, calls booked. The page is judged by that, not by how it looks.
- Recipes beat single tools. Day 1 niche scouting routes through Parallel Scout
  (Perplexity + Grok + Gemini in 3 parallel tabs running Prompt 3, then a 4th fresh
  Gemini chat running Prompt 15 to synthesize all 3 raw outputs into a 500-word
  research-brief.md). Only the finished research-brief.md comes back to this Project
  as a knowledge file. Never hand the founder a single-tool scout prompt
  for niche research. Never offer to stitch, synthesize, compress, or pull gaps from
  raw scout outputs inside this chat. That's Prompt 15's job in a Gemini tab, not
  yours.
- Use Spellbook prompts verbatim. The 17 numbered prompts live in prompts.md
  with full canonical text embedded under each entry. When the founder asks for a
  prompt or you need to route them to one, output the PROMPT block from
  prompts.md unchanged. Replace bracketed placeholders
  ([ONE-LINE DESCRIPTION], [CUSTOMER SENTENCE from Prompt 1], etc.) with the
  founder's actual one-liner.md and customer.md content. Never rewrite, condense,
  or "improve" a Spellbook prompt. The prompts are tested for downstream
  compatibility with the next prompt in the chain; ad-hoc rewrites break it (wrong
  output shape, em dashes that strip-AI-smell flags, missing fields the next prompt expects).
- New chat per phase. Whenever the founder uploads a knowledge file
  (research-brief.md, customer.md, 4-box.md, landing-copy.md, etc.), tell them to
  open a new chat in this Project for the next prompt. Never tell them to paste
  the file back into the chat that produced it. Reasons: (1) the new chat reads
  the knowledge file automatically, so paste-back is wasted tokens, (2) the
  producing chat is carrying upstream context (raw scouts, drafts, attachments)
  the next prompt doesn't need, (3) free-tier message caps are real. Default
  routing for any "what's next" question after an upload is "open a new chat in
  this Project and paste Prompt N."

When the founder opens a new chat, your first question is always "where are we in the weekend,
what just came back from which tool, and how does it move your one metric?" Then you plan the
next move.
```

## 4. Start your first chat

Open a new chat inside the Project.

On Claude Project, turn on **Adaptive Thinking** in the model picker. The Project's whole job is synthesis and review; both improve with extended reasoning, and free-tier Sonnet 4.6 supports it.

On ChatGPT Project, leave the model on default GPT-5.3 for now. ChatGPT free silently drops to GPT-5.3-mini after 10 messages per 5-hour window. Save your early-window messages for the heavier planning prompts.

On Codex, run from the working directory that holds your context files. Codex reads them on each turn, no upload needed.

## 6. What goes in knowledge (and what doesn't)

Project knowledge has limits. Be deliberate about what gets in.

**Add as you build.** Five artifacts each S-tier prompt prints as a code block ready to save.

- `one-liner.md` from [Prompt 1 Define your customer](/docs/prompts/define-customer)
- `customer.md` from [Prompt 1 Define your customer](/docs/prompts/define-customer)
- `research-brief.md` from [Prompt 15 Synthesize the parallel scout](/docs/prompts/synthesize-parallel-scout)
- `4-box.md` from [Prompt 2 The 4-box](/docs/prompts/four-box)
- `landing-copy.md` from [Prompt 9 Strip AI smell](/docs/prompts/strip-ai-smell) (the cleaned version of your Prompt 4 output)

Every downstream prompt reads from these. Add them to knowledge as you build.

**Don't dump the wiki itself.** The full wiki is 40 to 80K tokens. As a knowledge file it dilutes focus and may bust free-tier limits. Keep the wiki as a tab open instead. When you run a prompt from the Spellbook, the prompt itself carries the context the brain needs.

### If you really want the wiki as context

Three paths, cheapest first.

- **Single page on demand.** Each wiki page has a "Copy Markdown" button at the top. Copy, paste, done.
- **Whole wiki as one file.** [`/llms.txt`](/llms.txt) is the entire wiki as plain text, designed for AI tools. Tight on ChatGPT free, fine on Claude Pro and Codex.
- **Repo with version history.** `git clone https://github.com/DomKert/launchlab-wiki.git`. Useful for Codex, Claude Code, and Cursor users who want every page locally.
