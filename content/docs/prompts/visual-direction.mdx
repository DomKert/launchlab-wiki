## Why this works

You pick 3 references whose feel you want to match. Vision AI looks at all 3 and extracts the simplest possible visual direction: ONE vibe keyword from Bolt's vocabulary, 3 mood adjectives, and a Google Fonts pairing. That's it. The vibe keyword carries the visual DNA; everything else (palette, radius, shadow, spacing) gets picked downstream by ChatGPT or Bolt based on what works for that vibe.

The output gets pasted into [Prompt 17 Build prompt](/docs/prompts/bolt-build) where Claude assembles it into a final prompt for your build tool.

## Before you run this

Three things ready:

1. Three reference screenshots, picked from one of these catalogs:
   - [saaslandingpage.com](https://saaslandingpage.com), curated SaaS pages with conversion breakdowns
   - [lapa.ninja](https://lapa.ninja), clean indie / waitlist / solo-founder pages with strong typography
   - [landingfolio.com](https://landingfolio.com/inspiration/landing-page/saas), 340+ filterable pages

   Pick exactly 3 sites you'd be happy if your page felt like. Cmd+Shift+4 on Mac, Win+Shift+S on Windows. Hero-only screenshots are fine.

2. Your One Metric from [Prompt 14](/docs/prompts/pick-your-metric). The vibe keyword recommendation depends on shape (waitlist gets brutalism, demo gets glassmorphism, etc.).

3. A new chat in [ChatGPT](https://chatgpt.com) or [Claude](https://claude.ai). Don't reuse your strip-AI-smell chat from Prompt 9.

## Prompt

```txt
[Attach 3 reference screenshots above this message]

I'm building a [WAITLIST / DEMO / E-COM / NEWSLETTER / SAAS-TRIAL / 1:1-BESPOKE] landing page this weekend. The 3 attached screenshots are pages whose feel I want to match. I don't care about their content, just the look.

Look at all 3 and extract the simplest possible visual direction. Output exactly this format inside one code block I can paste into the next prompt:

VIBE KEYWORD
Pick ONE from this vocabulary based on my shape and what the screenshots actually show:
- Waitlist: brutalism or hyper-minimalism
- Demo / B2B: glassmorphism or material-design
- E-com: claymorphism or skeuomorphism
- Newsletter: hyper-minimalism or retro/vaporwave
- SaaS trial: flat-design or material-design
- 1:1 bespoke: hyper-minimalism

Avoid neumorphism (low contrast, accessibility tax) and cyberpunk (too niche unless gaming or web3) unless the screenshots scream for them.

MOOD ADJECTIVES
Pick the 3 sharpest words to describe the unified feel of the references. No generic words like "modern", "clean", "professional". Use specific words like "rebellious", "obsessive", "warm", "sterile", "editorial", "playful", "raw", "luxe", "sun-baked".

TYPE PAIRING
One serif or display font for headlines, one sans for body. Pick from Google Fonts that match the vibe (e.g. Fraunces + Inter for editorial luxe, JetBrains Mono + Inter for terminal/brutalist, Playfair Display + Lato for refined). One sentence on weight and contrast.

That's the whole spec. No palette hex codes (let the build tool pick), no radius/shadow/spacing/spacing (let the build tool pick), no other directives. Three things only.

After the spec code block, give me one sentence explaining the choice. Refuse to add more even if I ask. The minimum spec is the point.
```

## Save the output

Save the spec code block as `style-spec.md` in your Claude Project knowledge (Files +, Add text content). [Prompt 18 Hero image prompt](/docs/prompts/hero-image-prompt) and [Prompt 17 Build prompt](/docs/prompts/bolt-build) read it from there automatically.

The 3 reference screenshots stay in their folder. They don't get attached to the build tool by default; the vibe keyword + mood is the compressed text version that survives.

## Why so minimal

Three reasons we cut palette / radius / shadow / spacing:

1. AI builders (ChatGPT, Bolt, Lovable) follow explicit specs literally. Hex codes from a screenshot extraction often produce muddy, dated palettes when applied to a fresh page because the colors that work in the reference depend on lighting, photography, and surrounding elements that don't transfer.

2. Vibe keyword carries the visual DNA. "Hyper-minimalism" tells a builder to use lots of whitespace, restrained type, off-white or charcoal bg, one accent. "Brutalism" tells it raw edges, oversized type, hard borders, bold palettes. The keyword is more compressed than 6 sliders.

3. Training data wins. ChatGPT and Bolt have seen thousands of well-designed "hyper-minimalism" landing pages. They can produce one with cleaner palette/spacing decisions than a vision extraction can compress out of 3 reference screenshots.
