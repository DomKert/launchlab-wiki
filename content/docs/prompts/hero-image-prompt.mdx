## Why this works

Image-gen prompts have a lot of moving parts (mood, palette, photo style, composition, subject, what to avoid) and getting any of them wrong produces SaaS-marketing slop (laptops, abstract gradients with floating UI cards, people pointing at screens). Filling the prompt by hand means risking a mismatch.

Claude walks you through the inputs one at a time using the picker vocab below, asks for the niche-specific pieces (subject choice, composition tweaks), then outputs the image-gen prompt as one code block. It also tells you which image tool to paste it into based on whether you need text in the image or just the hero shot.

This runs in Claude Project, not Gemini. The OUTPUT goes to the image tool.

## Before you run this

One thing ready in your Project knowledge or available to paste:

1. Your 4-box from [Prompt 2](/docs/prompts/four-box). Already in Project knowledge if you saved it there.

Style direction (mood + palette + photo style) gets picked inside this chat from the vocab below. No external style file needed.

## Pick your image direction

Glance at the vocab below before pasting. Claude will ask you to pick during the chat. 30 seconds of skim.

#### Mood adjectives (pick 3)

warm, refined, calm, raw, technical, editorial, austere, considered, weighty, soft, sharp, lush, urgent, playful, confident, premium, rebellious, quiet, generous, energetic.

#### Palette (pick 3 hex codes)

Easiest: pick a reference page, use Chrome DevTools color picker (open DevTools, click any element, color picker icon next to color values) or any web color picker browser extension to grab 3 hex codes from the reference. One background, one ink (text color), one accent.

Or pick from these 5 curated palettes:

1. `#F7F4ED` cream + `#1A1410` charcoal + `#C46A2B` terracotta. Editorial warm.
2. `#F8F8F6` off-white + `#0F0F0F` near-black + `#2D5BFF` cobalt. Minimalist tech.
3. `#EFEAE0` bone + `#1A1A1A` ink + `#6F8B6E` sage. Calm refined.
4. `#0A0A0A` black + `#F2F0EA` warm white + `#C7E04E` chartreuse. Brutalist modern.
5. `#F1ECDF` cream + `#3B2818` chocolate + `#D4A24A` soft gold. Luxe heritage.

#### Photo style (pick ONE)

`editorial still life`, `lifestyle scene`, `abstract texture`, `product close-up`, or `type-only with color blocks`.

## Prompt

Run this in your Claude Project chat. Claude walks you through 4 to 6 inputs, then outputs the image-gen prompt as one code block plus a tool recommendation.

```txt
I want a hero image for my landing page. Read my Project knowledge (4-box.md) and synthesize a single image-generation prompt I'll paste into Gemini Nano Banana or gpt-image-2.

Walk me through these inputs one at a time, in order. Pull from Project knowledge first if the answer is already there.

1. Niche or product framing. One short phrase, e.g. "rare Italian knitwear curation" or "B2B legal AI for solo lawyers". Pull from 4-box if it's there.
2. Mood. 3 adjectives from this bank: warm, refined, calm, raw, technical, editorial, austere, considered, weighty, soft, sharp, lush, urgent, playful, confident, premium, rebellious, quiet, generous, energetic.
3. Palette. 3 hex codes (background + ink + accent). Either picked from a reference page using a color picker, or one of the 5 curated palettes (warm editorial / minimalist tech / calm refined / brutalist modern / luxe heritage). Help me pick if I'm stuck.
4. Photo style. ONE of: editorial still life, lifestyle scene, abstract texture, product close-up, or type-only with color blocks.
5. Composition. Default is wide aspect (16:9 or 21:9) with 30% negative space on the right for headline overlay. Confirm or override.
6. Subject. Object-only (no people), one model figure, lifestyle group, or no subject (abstract texture only).

If a value is genuinely unclear, ask one focused question per turn. Don't fabricate a palette or mood.

When you have all six, output the final image-gen prompt as ONE code block. Use this exact structure with my values substituted:

---

Hero image for a [niche] landing page.

Mood: [3 adjectives]
Palette: [hex codes]
Style: [photo style]
Composition: [composition spec]
Subject: [subject choice]

No text in the image. No SaaS-marketing cliches (laptops, abstract gradients with floating UI cards, people pointing at screens). [Add "no model faces" if subject is object-only or abstract.] Treat it like the cover image of an editorial magazine for [niche], not a stock-photo site.

---

After the code block, recommend which tool to run it in:
- Gemini Nano Banana Standard (100/day): default workhorse for iteration
- Gemini Nano Banana Pro (2/day): save for the one final hero shot
- gpt-image-2 in ChatGPT (2-3/day): best when I need text-in-image, especially Hindi / Bengali / Japanese / Korean / Chinese
- Ideogram (10 credits/day): most predictable text-in-image rendering

Pick one based on whether my hero needs text in the image. If no text, route me to Nano Banana Standard. If text needed, route to gpt-image-2 or Ideogram.

Voice rule: don't fabricate niche details, don't guess at palette, don't add subjects I haven't approved. If I'm vague, ask one focused question and stop.
```

## After Claude outputs the image prompt

1. Open the recommended tool ([Gemini](https://gemini.google.com), [ChatGPT](https://chatgpt.com), or [Ideogram](https://ideogram.ai)).
2. Paste the code block.
3. Generate the image.
4. If it lands, download the file to disk. Save it inside the same folder you'll use for your landing page (so it sits next to `index.html`).
5. When you run [Prompt 17 Build prompt](/docs/prompts/bolt-build), tell the synthesizer chat you have a hero image file ready. For Path A (ChatGPT), you'll reference it as a relative path in the HTML. For Path C (Bolt), you'll attach it via the paperclip.

If the image misses, change ONE input (subject, composition, or photo style) and re-run. Don't pile new adjectives on. See [Prompting AI tools](/docs/notes/prompting-ai-tools) on what never works.

## What good looks like

One Claude chat, 4 to 6 turns, image-gen prompt in one code block. One Gemini run, image in hand under 5 minutes. File saved to disk, ready to attach when you run Prompt 17.

## What bad looks like

Skipping the synthesizer and writing the image prompt by hand, getting a generic stock-photo result, then burning 5 Nano Banana runs trying to fix it with adjective piles. The fix is upstream: change the photo-style input or the subject, don't pile descriptors.
