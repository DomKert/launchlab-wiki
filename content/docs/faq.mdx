Most of these come from "but what if" moments mid-weekend. Read once Friday morning so you don't lose 30 min Googling Saturday afternoon.

## Minimum deliverable

### What do I actually need to ship to count as having done LaunchLab?

Four things by Sunday night:

1. A **live URL** for your landing page (any public hosting, not Notion, not a Google Doc, not localhost) with a working CTA tied to your **One Metric**.
2. **Five distribution tactics run** across Day 2 and Day 3, picked from the [42-tactic menu](/docs/distribution).
3. **One public post** from your own account, linking your page on social or in a community.
4. **Show up for Demo Day**

### What does "shipped" not mean?

A figma mockup. A Notion doc. A "coming soon" page with no CTA. A page hosted on localhost. A page only your study buddies have seen. A page with a CTA that doesn't actually capture anything (decorative button, broken form, dead Stripe link).

If a stranger can't land on the URL, click the CTA, and have something happen, it didn't ship.

### My idea is a SaaS, an app, an e-commerce shop, something bigger than a landing page. What's my final product?

Same as everyone else's. A landing page about the idea, five distribution tactics run, one public post, Demo Day. The page sells the idea or captures interest. You're not shipping the SaaS in 3 days; you're testing whether anyone wants it. The CTA is a waitlist, an email signup, a "book a call," whatever moves your One Metric.

If your idea needs heavy explanation, the page works harder for you, not less. Treat the constraint as a forcing function: if you can't get a stranger to want it from one page, the underlying idea has work to do.

## Setup and tools

### Do I need a paid Claude account?

No. Free tier handles the weekend. You will hit the message cap at some point though, so save bigger asks for the morning when the daily quota resets.

### Claude is asking me to subscribe when I open the Project. What now?

Claude free tier supports Projects, Custom Instructions, and Sonnet 4.6. No paywall on any of that. If you're hitting a subscribe prompt, two likely culprits:

1. **You pasted the system prompt into the chat box, not into Custom Instructions.** Custom Instructions is a separate field on the Project (gear icon or "Edit project"). Pasting the Meta guide into a regular chat just sends a 2K-token message and can trigger a quota nudge.
2. **You toggled Opus or Deep Research.** Both are paid. Leave the model on Sonnet 4.6 with Adaptive Thinking on. That combination is free and handles the weekend.

If you've done neither and still see the prompt, screenshot it and ask Domen in Discord.

### What if Claude rate-limits me mid-weekend?

Wait it out (caps reset every 5 hours on free tier) or improvise. Most planning prompts can run in ChatGPT free or Gemini free if you paste the same context. The prompts in this wiki are not Claude-specific.

### My free-tier credits ran out mid-weekend. What now?

Switch to a free alternative for that step. Gemini free if Claude or ChatGPT is capped. Carrd free template if Bolt's daily token cap hits. Ideogram if Nano Banana credits are gone. Most steps in the weekend have at least 2 tool options on free tier; the [Tools page](/docs/tools) lists them. Don't pay; the weekend is built to fit on free tier.

### Do I really need ChatGPT AND Claude, or just one?

Both. Different jobs. Claude is the brain (planning, briefing, reviewing). ChatGPT is the executor (drafting copy, generating images, raw scouts). Trying to do everything in one tool burns the same daily quota twice on planning + execution.

### Which build path should I pick?

Default to Path A: ChatGPT writes the HTML, you drop it into Netlify Drop. Free, fast, no platform lock-in. Pick Path B (Carrd / Framer) if you want to start from a template instead of writing prompts. Pick Path C (Bolt) if you want a richer interactive feel and don't mind the 300K daily token cap.

### Do I have to use Path A, B, or C? Can I use another tool?

Use whatever you want. The three paths are starting points for students who want a recommendation. If you already use Webflow, Squarespace, Cursor, Lovable, v0, or anything else, use it. The deliverable is a live URL with a working CTA tied to your One Metric. The path doesn't matter; the live page does.

## Process and time

### How long does this actually take per day?

5 to 8 focused hours. Day 1 is heaviest (research + 4-box + One Metric + ship the page). Day 2 is distribution. Day 3 is the launch raid plus Demo Day prep. Plan for it like a sprint, not a hobby weekend.

### When do I do Day 1 tasks, before or after the live session?

Day 1 tasks are designed for Friday. Run through them whenever fits your schedule, before the live session or alongside it. The session is a checkpoint along the way and adds direction. The work itself is on you.

### What if I don't ship by Sunday night?

Ship what you have. A landing page with placeholder copy and one screenshot is enough to count. Iterate next week.

### Do I have to do all 42 distribution tactics?

No. The 42 are a menu. Pick 4 to 6 that fit your shape and run those on Day 2.

## Common stumbles

### My copy sounds like AI. What now?

Run [Prompt 9 Strip AI smell](/docs/prompts/strip-ai-smell) on it. Banned words, dead transitions, sentence shapes that read as AI. Then read it out loud. If you wouldn't say a word out loud at a coffee shop, rewrite it.

### My hero image looks generic. What now?

You probably ran one tool. The hero image flow fans out across Gemini Nano Banana, ChatGPT, and Ideogram in parallel; same prompt into all three, three options to compare. See [Prompt 18](/docs/prompts/hero-image-prompt). One tool is one perspective and one perspective produces stock-photo slop.

### I can't pick a One Metric. What now?

Pick the metric that judges whether this weekend worked. Easy-to-count metrics are tempting and usually the wrong choice. Run [Prompt 14](/docs/prompts/pick-your-metric) with your 4-box; Claude picks the upstream metric if two compete. If your 4-box is too vague to pick from, the prompt asks you one question and stops. That question is the answer.

### My idea feels weak. Should I switch?

Probably no. Day 1 is the wrong day to switch. LaunchLab is for shipping. Run the niche scout (Prompt 3) and the 4-box (Prompt 2); usually the friction is shape, and shape can be fixed without changing the idea.

### Can I use an existing project I'm already working on, or do I need to start fresh?

Bring whatever you're excited about. The wiki works either way. The constraint is that LaunchLab compresses to one landing page + One Metric + at least 5 distribution tactics. If your existing project is bigger, you're still landing one page about it for this weekend. Don't try to ship the whole product in 3 days; pick the one page that gets your One Metric moving.

## Logistics

### Do I have to show up for Demo Day?

Yes. Sunday's session is the deadline.

### Can I keep using this wiki after the weekend?

Yes. The wiki stays up. The prompts work for any 3-day sprint, not just LaunchLab. Bookmark it and run it again next time you have a weekend free.

### Do I need to know how to code?

No. That's the point. Path A (ChatGPT + Netlify Drop) is HTML you don't write. Path B (Carrd / Framer) is templates. Path C (Bolt) is one-shot generation. Pick the path with the least code if code intimidates you.
